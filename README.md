Тема: Администрирование Linux. Базовые настройки системы.

Пользователи:
обычные и суперпользователи

Root
Имеет UID=0. Root может выполнять все операции. Он игнорирует все права, которые поставили другие пользователи, может переключаться за любого другого пользователя.

Не рекомендуется работать с root правами, по двум причинам:
Угроза безопасности и риск различных ошибок.

Добавление нового пользователя = useradd


-b базовый каталог для размещения домашнего каталога пользователя по умолчанию /home
-d домашний каталог в ктором будут размещаться файлы пользователя
-с комментарий к учетной записи 
-е дата блокировки пользователя
-f блокировки учетной записи сразу после создания
-g основная группа пользователя

Удаление пользователя = userdel

-f принудительное удаление пользователя и каталога даже если он не находится в системе
-r удаление пользователя с каталогом и почтовым ящиком

Права доступа
каждый файл принадлежит 1 пользователю и 1 группе, чтобы узнать ls -I
